How to Read Text Diffs

  • Side-by-Side: Best for wide monitors when auditing structural code changes or multi-line rewrites.
  • Unified View: Mimics standard Git commit patches (`diff -u`), stacking deletions above additions.
  • Word Highlights: Bright colored segments identify the specific tokens or words modified inside the line.

Frequently Asked Questions

Is my source code sent to a server?

Never. Text Diff Checker runs 100% in your browser's V8 engine. No network packets are transmitted, making it safe for proprietary code, API tokens, and confidential contracts.

What file types are supported?

Any plain text file format: JavaScript (.js, .ts), JSON, Markdown, HTML, CSS, YAML, Python, SQL, plain logs (.log), and config files (.env, .ini).

How is similarity calculated?

We compute the Longest Common Subsequence (LCS) ratio between the character and token sets of both texts: (2 * LCS) / (Len1 + Len2) * 100%.
