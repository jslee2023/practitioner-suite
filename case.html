When to Use Each Casing Convention

Industry standard naming patterns across modern programming stacks, databases, and copywriting.

camelCase helloWorld

Standard convention for variables, functions, methods, and JSON attributes in JavaScript, TypeScript, Java, and Go.

PascalCase HelloWorld

Used for React/Vue components, TypeScript interfaces, type definitions, C# classes, and Python class names.

snake_case hello_world

Predominant convention in Python scripts, PostgreSQL and MySQL column names, Ruby methods, and Rust variables.

kebab-case hello-world

Universally applied in CSS class selectors, HTML custom attributes, REST URL paths, and npm package identifiers.

CONSTANT_CASE HELLO_WORLD

Mandatory for environment variables (.env), immutable constants, and enum keys across nearly all languages.

Title Case Hello World

Essential for UI navigation items, modal dialog headings, documentation chapters, and article headlines.

Frequently Asked Questions

How does the parser handle mixed alphanumeric words and abbreviations?

The regex engine recognizes boundary transitions between lowercase and uppercase letters (e.g. getHTTPResponse becomes words get, HTTP, and Response), along with underscores, hyphens, and whitespace.

Can I batch convert lists of database columns or enum keys?

Yes! Simply enable "Line-by-Line Mode" in the options toolbar above. Each line will be parsed and formatted as an independent entity while preserving order.

What does "Inverse Case" do?

It reverses each individual character's casing (uppercase becomes lowercase and vice versa). This is a lifesaver when text was accidentally entered while Caps Lock was active.
