What is a Cryptographic Hash Function?

A cryptographic hash function maps arbitrary data to a fixed-size digest. Hashes are deterministic, irreversible, and exhibit the avalanche effect (minor input changes completely alter output).

Algorithm Output Bits Hex Length Collision Resistance Best Use Cases
MD5 128 bits 32 chars Broken Checksums, deduplication
SHA-1 160 bits 40 chars Weak Git commit trees, legacy files
SHA-256 256 bits 64 chars High (Standard) Software releases, TLS, file integrity
SHA-384 384 bits 96 chars Very High Subresource Integrity (SRI)
SHA-512 512 bits 128 chars Maximum Financial auditing, long-term archive
